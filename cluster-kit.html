2. Rack build order

  • Sort the screws by length before you start. They look alike and the manual calls for a specific one at every step.
  • Check every corner of the side frames is square while tightening. A frame that's slightly off makes the panels hard to slide in later.
  • Don't overtighten the handles, they screw straight into the acrylic.
  • Dry-fit every tray and cradle before you screw in the first device.
  • Fit the switch tray first. In my build it had to go in before the nodes, so everything came out again.
  • Put the power bricks behind the nodes and plug them into the PDU.
  • Leave the top slot free if you plan a KVM over IP.
  • Two cables per node: one port for storage, one for everything else. Don't bond them (the reasoning is in the network design post).

3. Network plan, decided before you install

  • nic1: storage only (Ceph), MTU 9000.
  • nic2: a bridge (vmbr0) with no address of its own, carrying the VMs.
  • On that bridge: a management VLAN with the gateway, and a separate VLAN for Corosync, the cluster heartbeat.
  • Write down every node's hostname (full name, for example pve1.lab.example.com) and its address on each network.

4. Install checklist, per node

  • Wipe the NVMe disks before you start (wipefs -a /dev/nvme0n1). An old partition table is what gave me a 1 KB OSD.
  • Mount the Proxmox ISO through the KVM as virtual USB, or boot from a stick.
  • In the installer, tick pin network interface names so a kernel update can't rename your ports.
  • Hostname is the full name, and the IP is a static address, not the DHCP one.
  • Read the installer's summary page like a checklist before pressing install. A wrong hostname is four minutes to fix now and an afternoon later.
  • After the first boot, switch to the free repositories (the community post-install script does this).
  • Apply the network plan: storage address and MTU 9000 on nic1, vmbr0 on nic2, management and Corosync VLANs on the bridge.

5. Cluster, Ceph and backups

  • Create the cluster with two links: the Corosync VLAN as link 0 and the storage network as link 1.
  • When a node joins, check link 1 is filled in. "Authentication failed" right after a join is normal, just log in again.
  • Install Ceph from the wizard on all three nodes, then add monitors and managers on the other two.
  • Create one OSD per node from the GUI and set the device class to NVMe by hand if it's detected wrong.
  • Create a pool for VM disks and CephFS for ISOs and templates, then disable local storage so nothing lands on one node by accident.
  • Attach Proxmox Backup Server, restore a real VM onto Ceph as a test, and schedule a nightly backup job.

6. Real certificates on internal nodes

  • Datacenter, ACME: register a Let's Encrypt account.
  • Add the Cloudflare DNS plugin with an API token that can only edit DNS on that one zone.
  • Per node, System, Certificates, ACME: add the node's full name and order the certificate.
  • Open the node by name afterwards, not by IP, or the browser will refuse the certificate.
