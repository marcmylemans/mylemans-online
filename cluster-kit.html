      Rack build order
      • Sort the screws by length before you start. They look alike and the manual calls for a specific one at every step.
      • Check every corner of the side frames is square while tightening. A frame that's slightly off makes the panels hard to slide in later.
      • Don't overtighten the handles, they screw straight into the acrylic.
      • Dry-fit every tray and cradle before you screw in the first device.
      • Fit the switch tray first. In my build it had to go in before the nodes, so everything came out again.
      • Put the power bricks behind the nodes and plug them into the PDU.
      • Leave the top slot free if you plan a KVM over IP.
      Install tips the planner doesn't cover
      • Wipe the NVMe disks before you start (wipefs -a /dev/nvme0n1). An old partition table is what gave me a 1 KB OSD.
      • Mount the Proxmox ISO through the KVM as virtual USB, or boot from a stick.
      • After the first boot, switch to the free repositories (the community post-install script does this).
      • When a node joins, "Authentication failed" right after the join is normal, just log in again.
      • Set the OSD device class to NVMe by hand if it's detected wrong.
      • Create a pool for VM disks and CephFS for ISOs and templates, then disable local storage so nothing lands on one node by accident.
      • Attach Proxmox Backup Server, restore a real VM onto Ceph as a test, and schedule a nightly backup job.
      Real certificates on internal nodes
      • Datacenter, ACME: register a Let's Encrypt account.
      • Add the Cloudflare DNS plugin with an API token that can only edit DNS on that one zone.
      • Per node, System, Certificates, ACME: add the node's full name and order the certificate.
      • Open the node by name afterwards, not by IP, or the browser will refuse the certificate.
